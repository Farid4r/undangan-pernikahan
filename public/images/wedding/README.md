# Foto undangan

Simpan foto lokal undangan di folder ini dengan nama berikut:

- `bride.jpg` — foto pengantin wanita
- `groom.jpg` — foto pengantin pria
- `cover.jpg` — foto latar halaman pembuka (saat ini file tersedia dengan nama `cover.JPG`, dan nama itu dipakai di konfigurasi)
- `save-the-date.jpg` — foto latar bagian Save the Date
- `gallery-01.jpg` sampai `gallery-12.jpg` — foto galeri

Jika memakai format lain, ubah ekstensi/nama file pada `config/wedding.ts`.
